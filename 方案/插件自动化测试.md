# 插件自动化测试方案 (V3 - Enterprise Ready)

这是一个基于 **Playwright + LLM + Chrome Extension** 的端到端自动化测试代理（Agent）方案。
本方案在 MVP 基础上，针对工程化落地的稳定性、安全性、准确性和体验进行了全方位升级。

---

## 1. 核心架构 (Architecture)

```mermaid
graph TD
    User[用户/插件] -- 1. 指令 + 当前URL --> Server[本地中间件 (FastAPI Agent)]
    
    subgraph "Browser Context (Chrome)"
        TargetPage[目标 Tab 页]
        DOM[DOM 结构]
    end
    
    Server -- 2. 连接 CDP (9222端口) --> Browser[Chrome 实例]
    Browser -- 3. 锁定目标 Tab (URL匹配) --> TargetPage
    TargetPage -- 4. 获取 Accessibility Tree --> Server
    
    Server -- 5. 页面结构 + 用户指令 --> LLM[大模型 (Brain)]
    LLM -- 6. 决策 (Function Call) --> Server
    
    Server -- 7. 执行动作 (高亮 -> 操作) --> TargetPage
    TargetPage -- 8. 执行反馈 (截图/日志) --> Server
    Server -- 9. 最终结果 --> User
```

---

## 2. 八大核心优化 (Key Upgrades)

| 维度 | 优化项 | 核心价值 | 实施方案 |
| :--- | :--- | :--- | :--- |
| **感知** | **上下文注入 (Context Injection)** | 让 AI "看懂" 页面，而非盲猜 | 使用 `accessibility.snapshot()` 获取精简的页面语义树，而非原始 HTML。 |
| **定位** | **Tab 页同步 (Target Sync)** | 防止操作错页面（如后台页） | 插件发送当前 `tab.url`，后端遍历 Context 锁定唯一目标 Page。 |
| **体验** | **可视化反馈 (Visual Feedback)** | 让用户知道 AI 要点哪里 | 执行 Click/Input 前，调用 `locator.highlight()` 高亮目标元素。 |
| **体验** | **流式/实时反馈** | 减少用户等待焦虑 | (进阶) 使用 SSE 推送执行日志；(基础) 实时返回详细的执行 Logs。 |
| **安全** | **Origin 校验 (CORS)** | 防止恶意网页调用本地 Agent | FastAPI 配置 `allow_origins` 严格限制为 `chrome-extension://<ID>`。 |
| **鲁棒** | **语义化定位 (Robust Selectors)** | 页面微调不影响脚本运行 | 优先使用 `get_by_role` / `get_by_text`，摒弃脆弱的 CSS Selector。 |
| **自愈** | **错误处理循环** | 遇到异常不直接崩溃 | 捕获 Playwright 异常，反馈给 LLM 或用户，支持重试机制。 |
| **易用** | **启动脚本封装** | 一键启动环境 | 封装 `.sh/.bat` 脚本，自动检测并开启 Chrome 调试端口。 |

### 补充：
- 关于“上下文注入” (Context Injection)：为了防止 Token 爆炸（复杂网页的 Accessibility Tree 依然很大），可以引入**“视口裁剪”**策略。只发送当前屏幕（Viewport）内的元素给 AI，如果 AI 觉得找不到，再滚动屏幕并发送下一屏的数据。
- 关于“Tab 页同步” (Target Synchronization)：除了匹配 URL，最好生成一个唯一的 session_id。插件生成 ID 传给后端，后端在 p.chromium.connect_over_cdp 后，可以通过执行一段简单的 JS (window.my_agent_id = 'xxx') 来标记并锁定正确的 Page 对象。
- 关于“流式输出” (Streaming)：流式输出不仅要输出文字，还可以输出**“中间状态截图”**。比如 AI 点击了按钮，立刻截一张小图通过 Base64 流回传给插件侧边栏，让用户有“看着它干活”的安全感。
- 关于“安全性” (Security)：在 FastAPI 中配置 CORS 时，allow_origins 应该严格填入 ["chrome-extension://<你的插件ID>"]
- 可视化反馈机制 (Visual Feedback / Highlighting)
问题： 用户看着页面，不知道 AI 到底想点哪里，心里没底。
方案： 在 Playwright 执行 click 之前，先注入一段 JS，给目标元素加一个红色的高亮边框 (border: 2px solid red)，停留 500ms，然后再点击。
价值： 极大地增强了工具的“可解释性”和“调试感”。
- 错误自愈机制 (Self-Correction Loop)
问题： 页面加载慢，AI 点击时元素还没出来，报错了怎么办？
方案： 不要在报错时直接抛出异常给用户。而在 Python 端捕获异常，把错误信息（如 TimeoutError）喂回给 LLM，让 LLM 决定是“等待 2 秒”还是“尝试另一个 Selector”。
架构变更： 这是一个 Think -> Act -> Observe -> (Error) -> Re-Think -> Act 的循环。

## 3. 后端实现 (Python Agent Host)

这是核心大脑。它负责连接浏览器、注入上下文、调用 LLM 并执行操作。

**文件名：`agent_server.py`**

```python
import json
import asyncio
from fastapi import FastAPI, Body, HTTPException
from fastapi.middleware.cors import CORSMiddleware
from playwright.sync_api import sync_playwright
from openai import OpenAI

# ================= 配置部分 =================
# ⚠️ 替换为你的 OpenAI Key
client = OpenAI(api_key="YOUR_API_KEY")

# ⚠️ 替换为你的插件 ID (chrome://extensions/ 可以查看)
# 这是安全性的关键，防止其他网站调用你的本地服务
EXTENSION_ID = "chrome-extension://nkNhJgNgBjOgPjNgKjMgLjMjMjNjOjOj" 

app = FastAPI()

# 安全配置：仅允许插件访问
app.add_middleware(
    CORSMiddleware,
    allow_origins=[EXTENSION_ID, "http://localhost:3000"], # 开发时允许 localhost
    allow_methods=["*"],
    allow_headers=["*"],
)

# ================= 核心工具集 (Tools) =================

def get_page_context(page):
    """
    [优化点 1] 上下文注入
    获取页面精简状态：URL, 标题, 和 Accessibility Tree
    """
    try:
        # snapshot() 自动过滤无用 div，只保留交互元素，节省 Token 且对 AI 更友好
        snapshot = page.accessibility.snapshot()
        # 简单的截断防止 Token 溢出 (生产环境可做更智能的视口裁剪)
        tree_str = json.dumps(snapshot, ensure_ascii=False)[:8000] 
        return f"Current URL: {page.url}\nTitle: {page.title()}\nAccessibility Tree:\n{tree_str}"
    except Exception as e:
        return f"Context Error: {str(e)}"

def locate_target_page(browser, target_url):
    """
    [优化点 2] Tab 页同步
    解决 '找错人' 问题：遍历所有 Context 找到 URL 匹配的 Page
    """
    target_clean = target_url.split('#')[0].split('?')[0]
    
    for context in browser.contexts:
        for page in context.pages:
            # 模糊匹配，只要 URL 包含核心路径即可
            if target_clean in page.url:
                page.bring_to_front() # 强制前置，优化体验
                return page
    return None

# 定义通用的原子操作工具 (Function Calling Schema)
tools_schema = [
    {
        "type": "function",
        "function": {
            "name": "perform_action",
            "description": "在页面上执行原子操作。必须基于 Accessibility Tree 的信息。",
            "parameters": {
                "type": "object",
                "properties": {
                    "action": {
                        "type": "string",
                        "enum": ["click", "fill", "goto", "screenshot", "scroll"],
                        "description": "动作类型"
                    },
                    "selector_role": {
                        "type": "string",
                        "description": "元素的 Role (如 button, link, textbox)，语义化定位优先"
                    },
                    "selector_name": {
                        "type": "string",
                        "description": "元素的 Name (文本/Label/Placeholder)"
                    },
                    "value": {
                        "type": "string",
                        "description": "输入框的值 (仅 fill 有效)"
                    }
                },
                "required": ["action"]
            }
        }
    }
]

# ================= API 接口 =================

@app.post("/api/run_test")
def run_test_agent(payload: dict = Body(...)):
    user_prompt = payload.get("prompt")
    target_url = payload.get("url") # [关键] 插件传递当前 URL
    
    if not target_url:
        return {"status": "error", "logs": "缺少目标 URL，请确保在插件中正确传递。"}

    with sync_playwright() as p:
        try:
            # 1. 连接到现有的 Chrome 调试实例
            browser = p.chromium.connect_over_cdp("http://localhost:9222")
            
            # 2. 锁定目标页面
            page = locate_target_page(browser, target_url)
            if not page:
                return {"status": "error", "logs": "未找到目标标签页，请确保 Chrome 已打开且处于激活状态。"}

            # 3. 获取页面结构 (Context Injection)
            page_context = get_page_context(page)
            print(f"🤖 AI Context Loaded ({len(page_context)} chars)")

            # 4. 构建 System Prompt
            # [优化点] 提示 AI 使用语义化定位
            messages = [
                {"role": "system", "content": f"""
                 你是一个 Playwright 自动化测试专家。
                 你拥有的唯一信息是当前页面的 Accessibility Tree。
                 
                 当前页面状态:
                 ---
                 {page_context}
                 ---
                 
                 任务: 根据用户指令，分析 Tree，找到最可能的元素，调用 perform_action。
                 ⚠️ 规则：
                 1. 优先使用 role 和 name 进行语义化定位 (Robust Selectors)。
                 2. 如果需要输入，请使用 fill 动作。
                 """},
                {"role": "user", "content": user_prompt}
            ]

            # 5. LLM 决策
            response = client.chat.completions.create(
                model="gpt-4o", 
                messages=messages,
                tools=tools_schema,
                tool_choice="auto"
            )
            
            tool_calls = response.choices[0].message.tool_calls
            logs = []

            if tool_calls:
                for tool in tool_calls:
                    if tool.function.name == "perform_action":
                        args = json.loads(tool.function.arguments)
                        action = args.get("action")
                        role = args.get("selector_role")
                        name = args.get("selector_name")
                        val = args.get("value")
                        
                        # 6. 执行操作 (Action Execution & Robustness)
                        try:
                            # [优化点 6] 鲁棒性定位策略
                            locator = None
                            if role and name:
                                locator = page.get_by_role(role, name=name)
                            elif role:
                                locator = page.get_by_role(role).first
                            elif name:
                                locator = page.get_by_text(name).first
                            
                            if locator and locator.count() > 0:
                                # [优化点 3] 可视化反馈：高亮元素
                                locator.highlight()
                                # 稍微等待一下让用户看清
                                page.wait_for_timeout(500) 
                                
                                if action == "click":
                                    locator.click()
                                    logs.append(f"✅ Clicked: {role or 'Element'} '{name}'")
                                elif action == "fill":
                                    locator.fill(val)
                                    logs.append(f"✅ Filled: '{val}' into '{name}'")
                                elif action == "screenshot":
                                    path = f"screenshot_{role}_{name}.png"
                                    page.screenshot(path=path)
                                    logs.append(f"📸 Screenshot saved: {path}")
                            else:
                                logs.append(f"⚠️ Element not found: role={role}, name={name}")
                                
                        except Exception as e:
                            # [优化点 7] 错误捕获
                            logs.append(f"❌ Action Failed: {str(e)}")
            else:
                logs.append(f"🤖 AI Message: {response.choices[0].message.content}")

            browser.disconnect()
            return {"status": "success", "logs": "\n".join(logs)}

        except Exception as e:
            return {"status": "error", "logs": f"System Error: {str(e)} (请确保 Chrome 以 --remote-debugging-port=9222 启动)"}

if __name__ == "__main__":
    import uvicorn
    print("🚀 Agent Server running on http://localhost:8000")
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

## 4. 插件端实现 (Plugin Client)

插件负责获取当前环境信息并发送给后端。

**代码片段 (App.vue / sidepanel.js):**

```typescript
// 发送测试指令的核心函数
async function sendTestInstruction(instruction: string) {
  // [优化点 2] 获取当前 Tab URL 用于后端锁定
  const [tab] = await browser.tabs.query({ active: true, currentWindow: true });
  
  if (!tab.url) {
      alert("无法获取当前页面 URL");
      return;
  }

  addMessage('ai', '正在分析页面结构并连接本地 Agent...');

  try {
    const res = await fetch('http://localhost:8000/api/run_test', {
      method: 'POST',
      headers: { 
          'Content-Type': 'application/json' 
      },
      body: JSON.stringify({
        prompt: instruction,
        url: tab.url // 关键：传入 Context
      })
    });
    
    const data = await res.json();
    
    if (data.status === 'success') {
        addMessage('ai', `执行报告:\n${data.logs}`);
    } else {
        addMessage('ai', `执行出错:\n${data.logs}`);
    }
    
  } catch (e) {
    console.error("Server connection failed", e);
    addMessage('ai', "连接失败。请确保：\n1. 本地 Agent Server 已启动 (port 8000)\n2. Chrome 已开启调试端口 (9222)");
  }
}
```

## 6. 预期工作流 (Workflow)

1.  **启动**：用户运行 `run_agent.sh`，确保 Chrome 以调试模式打开。
2.  **交互**：用户在插件侧边栏输入：“帮我把这个页面的所有表单都填上测试数据”。
3.  **分析**：
    *   插件将指令 + `https://example.com/form` 发送给 Server。
    *   Server 连接 Chrome，锁定 `example.com` 的 Tab。
    *   Server 提取 Accessibility Tree（发现有 `Name: Username, Role: textbox` 等）。
4.  **决策**：
    *   LLM 收到 Tree，决定调用 `perform_action(action='fill', selector_name='Username', value='test_user')`。
5.  **执行与反馈**：
    *   Playwright 找到输入框 -> **高亮红框** (用户看到) -> 填入数据。
    *   Server 记录 "✅ Filled 'test_user'"。
6.  **结果**：插件侧边栏显示执行日志，任务完成。
