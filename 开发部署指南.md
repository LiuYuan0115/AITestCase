## 🚀 快速开始

### 1️⃣ 打包前端扩展


| 命令 | 环境 | 智能体服务地址 |
|------|------|----------------|
| `npm run dev` | 开发 | `http://localhost:8765` |
| `npm run build` | 生产 | `http://192.168.108.240:8765` |

**配置文件说明**:
- `.env` - 开发环境配置
- `.env.production` - 生产环境配置

2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `solvely-mvp/.output/chrome-mv3` 目录

### 场景 2：新增接口

**示例：添加一个"总结"接口**

#### Step 1: 在 `agent_server.py` 中添加接口

```python
# ==================== 新增：总结智能体 ====================

# 1. 定义请求模型
class SummaryRequest(BaseModel):
    session_id: str
    text: str
    instruction: str = ""

# 2. 定义系统提示词
SUMMARY_SYSTEM_PROMPT = """
你是一个专业的文档总结助手。
请根据用户提供的文档内容，生成简洁明了的总结。
"""

# 3. 添加 API 路由
@app.post("/api/summary")
async def summary_agent(request: SummaryRequest):
    """总结智能体"""
    try:
        response = client.chat.completions.create(
            model="gpt-4o",
            messages=[
                {"role": "system", "content": SUMMARY_SYSTEM_PROMPT},
                {"role": "user", "content": f"文档内容：\n{request.text}\n\n用户指令：{request.instruction}"}
            ],
            temperature=0.7
        )
        
        result = response.choices[0].message.content
        return {"success": True, "result": result}
        
    except Exception as e:
        return {"success": False, "error": str(e)}
```

#### Step 2: 在前端 `api.ts` 中添加调用

```typescript
// solvely-mvp/src/api.ts

// 1. 定义接口类型
export interface SummaryOptions {
    sessionId: string;
    text: string;
    instruction?: string;
}

export interface SummaryResponse {
    success: boolean;
    result?: string;
    error?: string;
}

// 2. 添加 API 函数（使用环境变量，自动切换开发/生产环境）
export async function summaryAgent(options: SummaryOptions): Promise<SummaryResponse> {
    // 自动根据环境切换：开发用 localhost，生产用公司服务器
    const LOCAL_AGENT_URL = import.meta.env.VITE_LOCAL_AGENT_URL || 'http://192.168.108.240:8765';
    
    try {
        const response = await fetch(`${LOCAL_AGENT_URL}/api/summary`, {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({
                session_id: options.sessionId,
                text: options.text,
                instruction: options.instruction || ''
            })
        });
        
        return await response.json();
    } catch (error) {
        console.error('Summary Agent Error:', error);
        return { success: false, error: String(error) };
    }
}
```

#### Step 3: 在 Vue 组件中调用

```typescript
// solvely-mvp/src/entrypoints/sidepanel/App.vue

import { summaryAgent } from '@/api';

// 在需要的地方调用
const handleSummary = async () => {
    const result = await summaryAgent({
        sessionId: 'summary-' + Date.now(),
        text: '要总结的文档内容...',
        instruction: '请用三句话总结'
    });
    
    if (result.success) {
        console.log('总结结果:', result.result);
    } else {
        console.error('总结失败:', result.error);
    }
};
```
